# Prism Afterglow

Requires NextUp beta.27 or later. Import `Prism-Afterglow.nextup.json` through
Stream widgets → Add widget → Save as new widget. Use the resulting URL in an
OBS Browser Source at 960 × 280. Keep NextUp running.

Live album art, artist/title/requester, scrolling titles and smooth gradient
progress are supplied by NextUp. The equalizer follows your existing audio mode.
Colors, fonts, size and element positions remain editable in the widget designer.

Between songs, the card folds vertically into a line and horizontally into a dot.
It opens in reverse when the next song plays. A paused track stays visible. Idle
playback leaves the dot on screen. The saved preview uses live playback; the editor
shows the entire design. Reduced motion uses instant state changes.

No image assets or custom font installation are needed. The preview's album art
and track names are examples; the real widget uses the currently playing track.
